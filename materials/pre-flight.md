# Pre-flight check reference

Before producing the output zip, latex2arxiv validates the project against [arXiv's LaTeX submission guide](https://info.arxiv.org/help/submit_tex.html). `[error]` lines block submission (the tool exits non-zero); `[warn]` lines are advisory.

## Checks

| Severity | Trigger | Why it matters |
|---|---|---|
| 🛑 error | `\usepackage{minted}` / `pythontex` / `shellesc` | Require `--shell-escape`; arXiv compiles without it. For `minted`, a root `_minted/` holding minted v3 cache files (`*.minted`, built on TeX Live 2025) downgrades this to a warn. |
| 🛑 error | `\usepackage{auto-pst-pdf}` / `pst-pdf` | Require `--shell-escape` to convert PostScript figures; arXiv compiles without it. |
| 🛑 error | `\usepackage{svg}` | Shells out to Inkscape; arXiv does not provide it. Convert `.svg` to `.pdf` or `.png`. |
| 🛑 error | `\usepackage{psfig}` | arXiv no longer supports the psfig package. |
| 🛑 error | Shipped `psfig.sty` in submission | arXiv forbids user-supplied `psfig.sty`; it will cause the build to fail. |
| 🛑 error | `\usepackage{fontspec}` / `unicode-math` without a XeLaTeX opt-in | Fail under pdfLaTeX. Add a `00README.json` with `{"process": {"compiler": "xelatex"}}`, or select xelatex when submitting. |
| 🛑 error | `00README` / `00README.json` sets `compiler: lualatex` | arXiv supports tex, pdftex, latex, pdflatex and xelatex only; any other compiler fails the submission. |
| 🛑 error | `\tikzexternalize` without pre-built `*-figure*.pdf` | arXiv can't run shell-escape to externalize TikZ figures; build them locally first. |
| 🛑 error | `\addbibresource` of a non-BibTeX file (`.ris`, `.json`, ...) with no `.bbl` | Biber reads only BibTeX and biblatexml, so the entries are missing. |
| 🛑 error | `\addbibresource{refs}` without the `.bib` extension, no `.bbl` | Biber does not add `.bib`. |
| 🛑 error | `\bibliography{foo}` or `\addbibresource{foo.bib}` but `foo.bib` missing and no `.bbl` shipped | arXiv will block the submission if referenced `.bib` files are missing and no pre-built `.bbl` is provided. |
| ⚠️ warn | `\usepackage{xr}` or `xr-hyper` | File paths/locations differ on arXiv; external-document references break. |
| ⚠️ warn | Main `.tex` not at the submission root | arXiv compiles from the root, so `\input`, `\includegraphics` and bibliography paths resolve from there. |
| ⚠️ warn | `\input` / `\include` / `\subfile` / `\includegraphics` target not found in the project | arXiv's build stops with "File not found". Skips TeX Live files (checked with `kpsewhich` when installed), `filecontents` outputs, build outputs and verbatim; image checks are skipped when `\tikzexternalize` is used. |
| ⚠️ warn | `\usepackage{minted}` with a shipped `_minted` cache | Every listing must already be in the cache; build it with TeX Live 2025 (minted v3) and select TeX Live 2025. |
| ⚠️ warn | `\pdfoutput` set while `00README` selects xelatex or latex | xelatex has no `\pdfoutput`; latex+dvips needs DVI output. |
| ⚠️ warn | `\pdfoutput=0` without a latex `00README` | pdflatex then writes DVI, not PDF. |
| ⚠️ warn | `00README.yaml` / `00README.yml` | Not a format arXiv documents and not read as a processor choice; use `00README.json` or the legacy `00README.XXX`. |
| ⚠️ warn | `.tex` file inside `anc/` | arXiv says TeX files do not belong in the ancillary directory. |
| ⚠️ warn | `\printindex` / `\printglossary` / `\printnomenclature` without matching `.ind` / `.gls` / `.nls` | arXiv doesn't run makeindex or glossary processors; the printed section silently disappears. |
| ⚠️ warn | Remote `\addbibresource` URL with no `.bbl` | arXiv's build may have no network access. |
| ⚠️ warn | Custom `.sty` / `.cls` kept | arXiv may say they look unused; keep them, they are needed to compile. |
| ⚠️ warn | Undefined citations | `\cite{key}` with no entry in any kept `.bib` / `.bbl`. |
| ⚠️ warn | `.bib` generated by `filecontents` with no `.bbl` shipped | arXiv may block a submission without the `.bib`; ship it as a separate file. |
| ⚠️ warn | Shipped `.bbl` has bbl format 3.2 (biblatex 3.17–3.19) | Accepted only when TeX Live 2023 is selected at submission — a choice arXiv plans to retire. Regenerate with biblatex ≥ 3.20 (bbl format 3.3). |
| ⚠️ warn | Shipped `.bbl` has a bbl format other than 3.3 | arXiv hard-errors on bbl-version mismatches; regenerate under a current TeX Live or let arXiv run Biber from the `.bib`. |
| ⚠️ warn | BibTeX-format `.bbl` (`\bibitem`) in a biblatex document | Backend and `.bbl` must match ("do not mix"); regenerate with Biber (or the biblatex bibtex backend). |
| ⚠️ warn | Bundled `biblatex.sty` in the submission | arXiv provides its own biblatex; outdated bundled copies break compilation ("Patching \MakeUppercase failed"). |
| ⚠️ warn | `\documentclass[referee]` / `[doublespace]` / `\doublespacing` | arXiv requires single-spaced submissions. |
| ⚠️ warn | `\today` inside `\date{...}` | arXiv may rebuild the PDF; the date will change. |
| ⚠️ warn | `\includeonly` detected | Restricts which chapters arXiv compiles; remove it so the full paper appears. |
| ⚠️ warn | `\subfile`'d document containing `\bibliographystyle` | Likely a standalone supplement; remove the `\subfile` line to avoid duplicate bibliography commands. |
| ⚠️ warn | Absolute path in `\input` / `\include` / `\includegraphics` | Build server can't resolve `/abs/...` or `C:\...`; use a path relative to the submission root. |
| ⚠️ warn | `-eps-converted-to.pdf` artifacts in source | arXiv does not perform on-the-fly eps→pdf conversion; convert figures yourself and update `\includegraphics` paths. |
| ⚠️ warn | `.eps` images shipped (pdflatex mode) | `pdflatex` doesn't support `.eps`; convert to `.pdf` or `.png`, or use `latex+dvips` via `00README`. Suppressed when `00README` specifies `compiler: latex`. |
| ⚠️ warn | Hidden files (dot-files/directories) in output | arXiv deletes files starting with `.` upon announcement; if your build depends on them, rename. |
| ⚠️ warn | PNG image exceeds 34 megapixels | arXiv flags oversized PNGs (since Feb 2026); consider `--resize` to downscale. |
| ⚠️ warn | `.tex` source not valid UTF-8 | Re-save as UTF-8 to avoid corrupted accented/special characters. |
| ⚠️ warn | Filename or directory name has spaces or non-ASCII characters | Breaks `\input` and `\includegraphics` resolution. |
| ⚠️ warn | Output `.zip` larger than 50 MB | arXiv has size limits; consider `--resize` or splitting supplementary materials. |
| ⚠️ warn | Uncompressed project larger than 50 MB | arXiv soft limit for source size; consider `--resize` or splitting supplementary materials. |

## Silent fixes

In addition to surfacing issues, the conversion silently fixes common pitfalls:

- Preserves `00README` / `00README.json` / `00README.XXX` files at root for arXiv processor hints.
- Keeps the root `anc/` directory (arXiv ancillary files) minus hidden files and build junk, without normalizing its `.bib` files; `--resize` skips it.
- Keeps root `_minted*` caches, minus hidden files and build junk, when minted is loaded. Only a minted v3 `_minted/` cache downgrades the minted error; a v2 `_minted-<jobname>/` cache is shipped but still errors.
- Strips comments and standard draft annotations (`\todo`, `\hl`, ...) and packages (`todonotes`, `comment`, ...).
